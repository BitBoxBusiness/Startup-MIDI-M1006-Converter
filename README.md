# Startup-MIDI-M1006-Converter

Bambu Lab MIDI → M1006 Converter

An open-source, browser-based tool for converting MIDI files into M1006 G-code startup sounds for Bambu Lab 3D printers.

The converter runs completely locally in your browser — no uploads, no server and no account required.

It includes MIDI parsing, audio preview, trimming, automatic voice selection, pitch protection, printer start-G-code presets, light/dark mode, multilingual support and a beginner/expert interface.

The goal of this project is to make creating custom Bambu Lab printer sounds simple, accessible and customizable for the community.
